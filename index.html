One’sAI
Lines How it works

One’sAI is the one-liner inside HearthTone.

01.
One song, one line

Play anything. During the song it writes a single line about it — in the player’s bottom bar, and never longer than a line.
02.
Nothing leaves this machine

No cloud, no profile, no upload. Title, artist and lyrics pass through memory once and are gone. They never cross the network.
03.
Your model, your machine

If Ollama runs on this computer, a local model writes the line. Which model is entirely up to you.
04.
Always works, never waits

No local model? A built-in word-frequency engine assembles the line itself. There is no “service unavailable”. There is always a line.
05.
The fewest words possible

It doesn’t write reviews or genre histories. One line, about how the song feels, and then it stops.
06.
Ships inside HearthTone

It isn’t a separate app. Install the HearthTone player, play anything, and the line is already there.
